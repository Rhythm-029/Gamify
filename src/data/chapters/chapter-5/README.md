# Chapter 5 Dossier: The Launch Decision (Controlled User Group Rollout)

## 📌 Executive Summary
The Phase 1 build (Appraisals, Attendance, and Leave) is deployed to staging and has passed initial functional tests. However, production readiness across ICICI Bank's 80,000 employees requires evidence, not assumptions. As the Project Manager, you evaluate readiness evidence, identify critical launch blockers, configure a 500-user 48-hour pilot, and build an evidence-based rollout plan.

## 🎯 Deliverables & Decisions
- **Stage 1 — Evidence Review**: Inspecting 5 readiness cards (Functional, Integration, Security, Performance, Rollback).
- **Stage 2 — Blocker Triage**: Isolating non-negotiable prerequisites (Peak-load testing, Production security approval, Rollback procedure & monitoring readiness).
- **Stage 3 — Controlled Rollout Plan**:
  - Sequencing pre-pilot prerequisites versus continuous pilot activities.
  - Configuring 500-user 48-hour pilot thresholds (Latency SLA, error rate telemetry, feedback channels, incident on-call).
  - Choosing post-pilot strategy: Phased expansion (500 → 5,000 → 80,000) based on verified evidence.
